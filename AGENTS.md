# AGENTS.md — where to go, what to read, how to search

This file is the map. **How** to work is in [CLAUDE.md](CLAUDE.md). Both apply to every agent,
whatever tool runs it.

brd14 is one contract: a 14-byte branded id, `3×[A-Z]` namespace + 11 base62 characters over a
`ts41|node10|seq12` snowflake. It is implemented independently in Go, C, Rust, Python, TypeScript,
TypeScript-over-WebAssembly and bash. The implementations share no code. They share the contract,
the vectors, and a differential parity run that proves them byte-identical.

## Start here, by task

| You are asked to… | Read first | Then touch | Prove it with |
|---|---|---|---|
| change behaviour (any language) | `docs/contract.md` → `tools/oracle.py` | the oracle *and* every tree, or none | `make vectors`, `make test`, `make parity` |
| fix a bug in one tree | that tree's `docs/<lang>.md`, its `Makefile` | that tree only | `make -C <tree> test`, `python3 tools/parity.py --only <shim>` |
| add an implementation | `docs/contract.md` § Parity shim protocol, `docs/architecture.md` | a new tree with `test bench harden clean conform` targets + a shim | register it in `tools/parity.py`, then `--require` |

| Go API | `go/README.md`, `docs/go.md` | `go/` | `go test ./...`, `TestAllocs` (0 allocs is a contract) |

## Commands

```bash
scripts/setup.sh [core|full]   # toolchains (idempotent); cloud sessions run it via the SessionStart hook
. scripts/env.sh               # GOTOOLCHAIN + PATH for this shell
make test                      # every tree's suite (sets BRD14_REQUIRE_VECTORS=1)
make parity                    # every shim vs the oracle
make vectors                   # regenerate vectors/ and fail on drift
make bench                     # every bench → bench/results/ (slow; pin with taskset)
make harden                    # sanitizers, Miri, fuzz, race, floor toolchains (slow)
python3 tools/parity.py --only go,c-,rust-,python,ts-,sh-,ex-   # by shim-name prefix
scripts/brd.sh help            # mint / encode / decode / date / at / valid / hash / node / config
```

Every tree's `Makefile` implements `test bench harden clean`; the trees with shims also implement
`conform`.

## Search recipes

```bash
rg -n 'AzL8n0Y58m7|162382637|503620799'        # the range guard: lexicographic and arithmetic forms
rg -n '1704067200000|1_704_067_200_000'        # the epoch, in every language
rg -n 'HELLO '                                 # every parity shim
rg -n 'ErrLength|ErrNamespace|ErrCharset|ErrRange|LENGTH|NAMESPACE|CHARSET|RANGE' --type go --type py --type ts --type rust --type c
rg -n 'max\(now|last \+ 1|nowPart|now_part'    # generator cell implementations
rg -n 'FNV|0x811C9DC5|2166136261|16777619'     # node derivation
rg -n '0xFF51AFD7ED558CCD|4283543511'          # hash32 (fmix64)
rg -n 'BRD14_REQUIRE_VECTORS'                  # vector suites and their skip/require rule
rg -n 'BRD_[A-Z_]+' scripts/                   # CLI settings
rg --files -g '*conform*'                      # shim entry points
```

## Where results, artifacts and backups go

| What | Where | Committed? |
|---|---|---|
| bench results | `bench/results/*.json` | yes, when a run is deliberate; never from a noisy smoke run |
| storage measurements | `tools/storage_probe/results.json`, `tools/storage_probe/*/results.json` | yes (article evidence) |
| build outputs | `build/`, `native/c/build/`, `native/rust/target/`, `ts/**/dist/` | no (gitignored) |
| generated wasm bytes | `ts/packages/brd14-wasm/src/wasm-bytes.ts` | no (built by `make -C ts wasm-bytes`) |
| agent worktrees | `.claude/worktrees/` | no (gitignored) |
| scratch files | the session scratchpad, uniquely named (parallel agents share it) | no |

## Branches

- `master` is the default branch and is pushed only by the Operator.
- Agents work on `claude/<topic>` branches, created from `origin/master`.
- Releases of the Go module are tagged `go/vX.Y.Z`, by the Operator only.
