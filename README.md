# brd14. Branded Identity.

A 14-byte branded identity: **time-ordered**, **coordination-free**, and carrying its own type —
one contract, implemented independently in every runtime of the stack and proven byte-identical.

```
USR0KHTOWnGLuC
└┬┘└─────┬────┘
 │       └─ 11 chars of Base62 over a ts(41)|node(10)|seq(12) snowflake, epoch 2024-01-01Z
 └───────── a 3-letter uppercase namespace — the brand IS the type
```

## Implementations

| Tree | Language / runtime | Variant | Install |
|---|---|---|---|
| [`go/`](go/) | Go ≥ 1.22 (developed on 1.26) | **reference** — zero-alloc hot path | `go get github.com/jonny-novikov/brd14/go` |
| [`native/c/`](native/c/) | C11, libc-only | `speed` · `memory` | vendor the folder; C ABI in [`native/include/branded_id.h`](native/include/branded_id.h) |
| [`native/rust/`](native/rust/) | Rust, `no_std` | `speed` · `memory`, C ABI drop-in, wasm32 | path dependency `brd14` |
| [`native/beam/`](native/beam/) | Erlang NIF over the C ABI | Rust or C core | `make -C native/beam` |
| [`python/`](python/) | CPython ≥ 3.12, incl. free-threaded 3.14t | pure | `pip install ./python` |
| [`ts/packages/brd14`](ts/packages/brd14/) | TypeScript on Node ≥ 24 and Bun ≥ 1.4 | pure (no BigInt in the hot path) | workspace package `brd14` |
| [`ts/packages/brd14-wasm`](ts/packages/brd14-wasm/) | TypeScript over Rust → WebAssembly | wasm | workspace package `brd14-wasm` |
| [`scripts/brd.sh`](scripts/brd.sh) | bash ≥ 4 | pure (CLI) | `scripts/brd.sh`, `scripts/mint.sh` |

They share **no code**. They share [the contract](docs/contract.md), the frozen
[`vectors/`](vectors/) generated by an independent oracle, and a differential
[parity run](docs/parity.md) that feeds every implementation the same inputs and compares the
outputs byte for byte.

<a id="quick-start"></a>

## Quick start

```bash
scripts/setup.sh        # pinned toolchains: Go 1.26.9, Python 3.14/3.14t, Node 24 LTS, Bun, Rust 1.99
. scripts/env.sh        # put them on PATH
make test               # every suite, against vectors/
make parity             # every implementation vs the oracle
make bench              # every benchmark → docs/benchmarks.md
```

<a id="shell-tools"></a>

## Shell tools

```bash
scripts/mint.sh            # KAN0R9P5pHj8mu   (ns from .brdrc)
scripts/mint.sh ORD 3      # three ORD ids, strictly increasing
scripts/brd.sh decode USR0KHTOWnGLuC     # ns, snowflake, date, ts, node, seq
scripts/brd.sh date USR0KHTOWnGLuC       # 2026-01-27T15:11:37.641Z
scripts/brd.sh at 2026-01-01T00:00:00Z   # the smallest id of that instant: a range-scan cursor
scripts/brd.sh config                    # effective settings and where each came from
```

Pure bash, no dependencies, proven byte-identical to the oracle by the parity run. Defaults come from
[`.brdrc`](.brdrc) (parsed, never sourced); see `scripts/brd.sh --help`.
